# Portfolio Images

## Como adicionar suas imagens:

### 1. Foto de Perfil
- **Nome do arquivo**: `profile.jpg`
- **Tamanho recomendado**: 500x500px (quadrada)
- **Formato**: JPG ou PNG
- **Descrição**: Sua foto profissional para a seção hero

### 2. Foto "Sobre Mim"
- **Nome do arquivo**: `about-me.png`
- **Tamanho recomendado**: 600x400px
- **Formato**: PNG (sem fundo) ou JPG
- **Descrição**: Foto mais descontraída para a seção sobre

### 3. Projetos
Adicione as imagens dos seus projetos na pasta `projects/` com os seguintes nomes:
- `project-1.jpg` - E-commerce Platform
- `project-2.jpg` - Mobile Task Manager  
- `project-3.jpg` - Dashboard Analytics
- `project-4.jpg` - Brand Identity
- `project-5.jpg` - Social Network
- `project-6.jpg` - Fitness App

**Tamanho recomendado**: 800x600px
**Formato**: JPG ou PNG

### 4. Favicon
- **Nome do arquivo**: `favicon.ico`
- **Tamanho**: 32x32px ou 16x16px
- **Formato**: ICO

### 5. Currículo
- **Nome do arquivo**: `resume.pdf`
- **Formato**: PDF
- **Descrição**: Seu currículo para download

## Onde encontrar imagens placeholder:

Enquanto você não tem suas próprias imagens, pode usar sites como:
- **Unsplash** (https://unsplash.com) - Fotos gratuitas de alta qualidade
- **Pexels** (https://pexels.com) - Fotos e vídeos gratuitos
- **Placeholder.com** (https://placeholder.com) - Imagens placeholder
- **Lorem Picsum** (https://picsum.photos) - Imagens aleatórias

### Exemplo de URLs para placeholder:
```
Foto de perfil: https://picsum.photos/500/500?random=1
Sobre mim: https://picsum.photos/600/400?random=2
Projetos: https://picsum.photos/800/600?random=3
```

## Otimização de imagens:

Para melhor performance, otimize suas imagens:
1. **Compressão**: Use ferramentas como TinyPNG ou Squoosh
2. **Formato**: Prefira WebP quando possível
3. **Tamanho**: Não use imagens maiores que o necessário
4. **Alt text**: Sempre adicione descrições para acessibilidade
